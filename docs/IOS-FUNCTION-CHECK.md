# iPhone 版功能状态与验收清单

## 当前交付边界

安装包内含 Folia 本地网页资源，不内置网易云、QQ 或酷狗服务，也没有附送可试听歌曲。
本轮修复增加手机运行时服务设置、连接检测、三平台应用存储会话隔离和局部原生 JSON 请求；没有用户自建接口或音乐账号参与真实在线验收。
“已实现”表示源码与自动化可检查的路径，不表示已在 iPhone 完成登录、播放或账户写入。
打包成功、浏览器 WebKit 布局测试通过也不等于真机全部功能通过。

## 本轮修复

- 在 **设置 → 连接与集成 → 音乐服务连接** 分别配置三平台地址，保存并刷新，无需重新编译。
- 网易不再无条件标为已配置；三平台的未配置状态与实际接口地址一致。
- 地址校验、只读连接检测、保存和登录播放采用不同结果，不把格式正确当作服务可用。
- 地址变化时清除对应旧会话，并按服务地址拒绝加载旧账户快照；配置不会传回仓库。
- 上述清理只覆盖应用本地存储，不覆盖系统 Cookie。原生 HTTP 的默认 Cookie 存储可能在同域不同路径间共享；`credentials: 'omit'` 不控制原生 Cookie，同域换服务与账户切换待真机验收。
- 三平台及连接检测的小型 JSON 通过原生 HTTP 请求；不全局替换 fetch，不桥接音频大文件。
- 原生路径要求 HTTPS、拒绝嵌入账号与跨站点重定向，使用八秒超时；网页和桌面保留原有 fetch。
- 手机弹窗、输入和安全区另有布局修复；软键盘与系统增大字体仍纳入真机验收。

## 服务配置与部署

配置步骤见 `docs/IOS-BUILD.md`。Docker 网关的真实路径是 `/netease`、`/qq`、`/kugou`；不要套用 serverless 的 `/api/qq`。
统一 Folia 域名是辅助 API 的站点源地址，不会自动猜测三音源的路径。音乐官网不是兼容接口。
服务端密钥只留在服务器，不写进 VITE 变量、IPA、截图或公开日志。没有服务时三平台仍应显示未配置。
[Capacitor HTTP 官方说明](https://capacitorjs.com/docs/apis/http)列明局部原生请求及大文件桥接限制；音频流仍需单独验证。

## 真机验收（尚未执行）

1. 空配置/错误地址/错误路径 HTML/证书异常/超时；保存、刷新、重启；换服务清应用存储旧会话，并检查系统 Cookie 是否仍影响账户（尤其同域不同路径部署）。
2. 三平台分别扫码、过期/取消、确认后读回账户、杀进程恢复、退出；核对 QQ 支持通道。
3. 三平台分别搜索分页、普通歌曲播放、拖动/切歌、逐字歌词、纯音乐/无歌词、VIP/版权反馈。
4. 读取喜欢与歌单；用户选定测试歌单后再做单次写入，并重新读取确认；不测试 QQ 未实现的写入。
5. 自己的 Navidrome；文件选择/取消/非法格式、导出真实结果、缓存重启与离线命中。
6. 竖屏/横屏、安全区、软键盘、大字体、长内容滚动、确认和二维码弹窗、触控返回/关闭。
7. 前台/后台/锁屏、蓝牙耳机、来电中断、网络切换、锁屏切歌及回前台进度；未通过项保留待验收。
8. 外链、复制和系统分享边界；每项记录系统版本、源码提交、服务版本和实际结果，隐藏凭据。
